# Communication Programme

A daily calendar app for the 6-month communication improvement programme (1 Oct 2026 – 31 Mar 2027).

- Click any date to see that day's tasks, tick them off and add an end-of-day note.
- Today's date is highlighted. Progress and notes are saved in your browser.
- Use **Backup** / **Restore** (bottom right) to move your progress between devices.

## Put it on GitHub Pages
1. Create a new repository and upload `index.html` (keep that exact name).
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. After a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.

Note: progress is stored per browser and per device, so use Backup/Restore if you switch.
